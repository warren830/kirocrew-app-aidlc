## 根因与修复

审计问题投影曾将所有 `Options` 值解释为可直接发送的选项。
只有 `Free-text note` 的检查点因此失去正文输入能力，后端也拒绝自由文本。
代理没有为标签回复记录 `QUESTION_ANSWERED`，使旧操作一直停留在 Processing。

- 仅识别明确的 `Free text` / `Free-text note` 单一标记；`Add a note` 和普通枚举保持原义。
- 输入框初始为空，空白和标记本身不能发送；已发送或已关闭的卡片只展示记录。
- 发送正文时保留中文、标点和换行；回执核对使用引擎的换行转义及项目路径脱敏规则。
- 恢复旧回合要求代理已经结束、原审计问题仍待答、旧消息只有标记，并通过人工回合与游标核对。
  只释放该操作拥有的租约，不生成答复或审批证据。
- 历史记录显示“仍需补充正文”；再次提交被拒绝时，不再误称此前也未发送任何内容。
