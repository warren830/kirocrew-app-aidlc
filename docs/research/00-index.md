## PRD-critical questions — where they are answered

| How does an in-gateway app submit a **human** prompt to a KiroCrew session? | In-process from the route handler: `state = request.app["state"]`; require `is_owner_dashboard_request(request)`; get/create a slot with `project=<repo realpath>`, `agent="aidlc"`, `app="aidlc-studio"`; under `slot._lock` check the busy predicates; `slot.append("user", text, "msg msg-u", meta={"studio_action_id": …})`; `slot._human_seen = True`; `task = spawn_guarded_turn(state, slot, state.run_background_turn(slot, _run_chat(state, slot, text, _directive_user_origin=True)))`; `slot.task = task`; observe the turn via the task / `chat_done`; then reconcile from disk. It is an ACP `session/prompt` → fires `userPromptSubmit` → `HUMAN_TURN` + `.aidlc-human-turn`. HTTP equivalent `POST /api/chat {"message","slot"}`. | 02 §2, §3.2, §4, §9 + addendum A2/A3; 01 §1.3 |

## Decisions the implementer must make

- **D1 — Backend module layout.** (a) relative imports + `minKiroCrewVersion: "0.5.0"`, tests on the bundle interpreter; or (b) `_sibling()` loader (08 §7.2), works on 0.3.0 and 0.5.0 and under the prototype test loader. Recommendation: (b) unless the test suite is moved to the 0.5.0 bundle python.
- **D2 — `minKiroCrewVersion`.** `0.3.0` (trust, spawn, `permissions.api`) vs `0.5.0` (relative imports, repository-bound trust, 30 s startup-hook deadline). Couples with D1.
- **D3 — Human-lane transport.** In-process `spawn_guarded_turn(… _run_chat …)` (write-before-send possible, no token, private-by-convention API → add a startup signature self-test) vs HTTP `POST /api/chat` from the backend with an app token (`/api/chat` in `permissions.api`, slot must be `_app == "aidlc-studio"`). Recommendation: in-process.
- **D4 — Live updates.** Own `/api/ws` WebSocket (unwrap `app_event`, re-dispatch `mc:app:*`), Studio SSE `GET /events` with resume cursor (PRD §15), or polling. `useAppEvents`/`useNotify` are dead on 0.5.0.
- **D5 — Slack quick actions.** No app-registered callback API; either (i) post `[OPTIONS:]`/`action::` buttons into a thread linked to the canonical slot (click becomes a human turn with the button label as wire text), or (ii) notification + deep link only, or (iii) propose a host seam (S7). PRD's `POST /slack/actions/callback` cannot be built as specified today.
- **D6 — Advisor substrate.** `ctx.spawn.run(task, agent="aidlc-studio--advisor")` (own agent from manifest `agents[]`, `approval_mode="auto"`, runs in pool cwd not the repo, evidence in-band) vs the side-conversation endpoints (`/api/chat/slots/{slot}/side/*`, isolated `side:<slot>` session). FR-ADV-002 fits SpawnSDK best; the runner agent's tool surface must be read-only.
- **D7 — Manifest cosmetics.** `ui.pages[0].route` value (`/apps/aidlc-studio` vs `/aidlc-studio`); `ui.entry` `index.mjs` (hand-written) vs `dist/index.mjs` (Vite lib build, committed); `permissions.api` with or without the redundant `/*` entry; `tags` category (`developer-tools`, `workflows`).
- **D8 — Bundled AI-DLC payload.** Vendor `wt-v2-triage/dist/kiro` (2.6.2) verbatim and pin `AIDLC_VERSION`/`CURRENT_STATE_VERSION`; decide how repos on 2.1.x/2.2.x (State Version 7) are handled (read-only view + "incompatible state" finding; upgrade blocked until the engine's own migration path is confirmed).
- **D9 — Resolved repo identity canonical display path** on case-insensitive APFS (`realpath` keeps typed case; inode identical) — choose a directory-listing case fix-up or accept the typed case.
- **D10 — Migration strictness (FR-MIG-005).** Disable `aidlc-console` before enabling `aidlc-studio` (no transient double rail row) vs preview-first with both enabled.
- **D11 — Read-only engine allowlist.** `intent --json`, `space --json`, `detect --json`, `config list --json` are stdout-only; `status` has no `--json`; `doctor` appends `HEALTH_CHECKED`/`GUARDRAIL_LOADED` and deletes leaked tmp locks → exclude from the backend allowlist or accept the side effects explicitly (PRD §12.3).
- **D12 — Queue column width** (`300px` mockup vs ≈36% PRD) and the collapsed status-strip appearance (06 §13 #1/#2).
- **D13 — Test interpreter.** Keep `/Users/ychchen/warren_ws/kirocrew/.venv/bin/python` (0.3.0 semantics, 66 tests pass) or switch to the bundle python (0.5.0 semantics, prints harmless config warnings).
